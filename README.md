# Keyboard Sender

Небольшая десктопная утилита для автоматизации ввода с клавиатуры.

Проект создается в учебных целях: здесь я не только реализую функциональность, но и стараюсь соблюдать хорошие практики разработки — понятную архитектуру, работу с Git, аккуратные коммиты и чистый код.

## Возможности

* Лёгкий интерфейс на CustomTkinter (~5–8 МБ в сборке)
* 8 встроенных тем оформления (светлые, тёмные, цветные)
* Настраиваемые горячие клавиши (F6 — запуск, F7 — остановка)
* Таймер автостопа (часы / минуты / секунды)
* Выбор повторяемых клавишей через окно раскладки клавиатуры
* Исправленная отправка клавиш через Win32 `keybd_event` (корректно работает с русской раскладкой)
* Сборка в один `.exe`

## Стек

* Python 3.13+
* CustomTkinter

## Логика работы

1. Приложение запускается, F6 начинает отправку выбранных клавиш по кругу
2. F7 останавливает работу (или кнопка «Стоп»)
3. Можно задать таймер автостопа
4. Кнопка «Клавиатура» открывает окно выбора повторяемых клавиш
5. Настройки сохраняются в `~/.clicker/config.json`

## Настройка

```bash
pip install -r requirements.txt
python main.py
```

Для сборки .exe:

```bash
pyinstaller main.spec
```
