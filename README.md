# KeyboardSender

Небольшая десктопная утилита для автоматизации ввода с клавиатуры.

Проект создается в учебных целях: здесь я не только реализую функциональность, но и стараюсь соблюдать хорошие практики разработки - понятную архитектуру, работу с Git, аккуратные коммиты и чистый код.

## Возможности

* Современный интерфейс на PySide6
* Настраиваемые горячие клавиши
* Изменяемая задержка между циклами
* Светлый минималистичный дизайн в пастельных тонах
* Сборка в один `.exe`

## Стек

* Python 3.13+
* PySide6
* keyboard

## Структура проекта

```text
KeyboardSender/
│
├── main.py         # Точка входа
├── ui.py           # Интерфейс
├── macro.py        # Логика макроса
├── styles.py       # Цвета и оформление
├── config.py       # Работа с настройками
│
├── resources/      # Шрифты, иконки и другие ресурсы
│
├── requirements.txt
├── build.bat
└── README.md
```
