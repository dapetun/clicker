# Keyboard Sender

Небольшая десктопная утилита для автоматизации ввода с клавиатуры (изначально называлась Clicker).

Проект создается в учебных целях: здесь я не только реализую функциональность, но и стараюсь соблюдать хорошие практики разработки - понятную архитектуру, работу с Git, аккуратные коммиты и чистый код.

## Возможности

* Современный интерфейс на PySide6
* Настраиваемые горячие клавиши (Z для запуска, Q для остановки)
* Изменяемая задержка между циклами (1-100 мс)
* Светлый минималистичный дизайн в пастельных тонах
* Сборка в один `.exe`

## Стек

* Python 3.13+
* PySide6
* keyboard
* PyInstaller

## Логика работы

1. Приложение запускается с помощью горячей клавиши Z (изначально была настройка trigger_key)
2. Нажатие Z активирует отправку алфавитных клавиш по порядку
3. Горячая клавиша Q останавливает работу
4. Задержка между циклами настраивается ползунком (1-100 мс)
5. Настройки сохраняются в `~/.clicker/config.json`

## Настройка

```bash
pip install -r requirements.txt
python main.py
```

Для сборки .exe выполните:

```bash
pyinstaller main.spec
```
